
# Contributing

Thank you for your interest!

## Development
- Create a feature branch from `main`.
- Add unit tests where applicable.
- Ensure the **Eval** workflow passes locally (`python src/eval/eval_runner.py ...`) and on PR.

## Commit hygiene
- Use conventional commits where possible (feat, fix, docs, chore).

## Pull Requests
- Include a brief description and screenshots of failing→passing evals when applicable.
